# Predicción de contratación de depósitos bancarios

Proyecto académico en equipo (UPM, Aprendizaje Automático).

## Qué hace

Predice si un cliente de un banco contratará un depósito a plazo. Combina tres modelos (KNN, árbol de decisión y regresión logística) mediante un modelo de votación (Voting).

## Contenido

`prediccion-depositos-bancarios.ipynb`: el análisis paso a paso, con una explicación antes de cada bloque de código.

## Cómo ejecutarlo

Instalar las librerías con `pip install -r requirements.txt`.

Colocar `train.csv` y `test_nolabel.csv` junto al notebook. Los datos del reto no se incluyen en el repositorio.

Abrir el notebook y ejecutar las celdas en orden.
